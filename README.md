# FuelPro-Dev

📌 FuelPro – Fuel Station Management System

FuelPro is a web-based Fuel Station Management System developed as a group project during Year 2 – Semester 1 of my Information Technology degree program. I contributed to the development of this system using Java Servlets, JSP, and MySQL, focusing on backend logic, data handling, and system functionality.

The system was designed to automate and streamline fuel station operations by managing vehicle registrations, fuel transactions, service scheduling, and administrative controls through a centralized web application.

🚀 Key Features

Vehicle and customer registration

Fuel and service record management

Service and maintenance booking

Admin and staff management

Secure database-driven operations

🛠 Technologies Used

Java Servlets & JSP

Apache Tomcat

MySQL

HTML, CSS, Bootstrap

JDBC

🎯 My Contribution

I worked on implementing backend functionalities, database connectivity, and several core modules of the system, ensuring reliable CRUD operations and smooth interaction between the web interface and the database.

This project helped me build strong foundations in web application development, database integration, and team-based software development.
